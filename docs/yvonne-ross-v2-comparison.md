# V1 → V2 visual comparison

Compared rendered V1 and V2 locally at 375, 390, 768, 1024 and 1440px; V2 was additionally inspected at 430, 1280 and 1728px. The first viewport and full page were examined, not just code differences.

| V1 weakness observed | V2 response observed |
|---|---|
| Warm paper, moss and bronze throughout | Digital black, graphite, porcelain and cool silver with small sapphire signals |
| Large serif headlines created a heritage mood | Geist variable sans, tight architectural display type and more deliberate scale contrast |
| Conventional split hero placed copy beside a small ring | Full-viewport dark campaign composition with oversized integrated type and an original macro form study |
| Three equal product tiles felt like catalogue cards | Wide, varied scroll-snap reel with larger visuals, direct official piece links and clear concept disclosure |
| Google rating was a thin strip below the mobile hero and a small late section | Rating now in the first viewport on desktop and mobile, followed immediately by an editorial 4.6 section and Google links |
| Minimal motion beyond button movement | Four restrained patterns: hero image reveal, hero type reveal, native reel scroll, CTA response; reduced motion supported |
| Mobile hero had long copy and review below the first screen | Shorter headline and copy, early rating above persistent call action, swipeable reel, no horizontal overflow |
| Studio followed another routine split section | Large typographic location lead, asymmetric map layout and prominent address/directions |
| Contact looked like a regular service page and card form | Oversized dark contact introduction, direct communication routes and quieter lined demo form |

V2 still uses abstract concept visuals. Licensed photography would improve tactile credibility further, especially in the product reel and designer story.
