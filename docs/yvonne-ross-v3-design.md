# V3 — The Light Studio

This is a separate branch from the darker Future Atelier V2. V3 keeps the same verified studio details, contact routes, product listings, dated review signal and no-send enquiry preview. It uses Yvonne Ross Jewellery's own photographs and official logo. No deployment has been made.

The direction is deliberately more approachable: warm ivory, pale sage and soft peach; sentence-case copy; rounded photo panels and CTAs; a lighter jewellery reel; and an aquamarine photograph in the opening. The rating remains in the first viewport and links to Google. At mobile widths, the call bar remains visible without covering that rating.

Official source URLs and the publication-rights caveat are in [the media register](./yvonne-ross-official-media-register.md). The V3 browser QA covered all four routes at 390 and 1440px with all images loaded. There were no page errors, broken images or horizontal overflow. The production build and all four conversion tests passed.
