# V2 media plan — Future Atelier

No Higgsfield asset is generated or shipped in this branch. The app uses original CSS form studies as replaceable concept visuals. Product photographs and Yvonne's likeness require separate authorisation. Generated jewellery must never be described as her actual inventory or actual studio.

| Slot | Format | Art direction | Current fallback / code location |
|---|---|---|---|
| H01 — desktop hero | Static 16:9 or 21:9, ideally 2560px wide | Monumental abstract metal/mineral form, cool graphite/silver, space for type on left | `HeroMedia` / `Artwork kind="hero"`; optional desktop video and poster props |
| H02 — mobile hero | Static 4:5 or 9:16, 1600px minimum long edge | Vertical companion form with dark text-safe lower zone | `HeroMedia` mobile poster prop; original CSS art until supplied |
| H03 — bespoke | 4:5 or landscape crop | Sculptural metal, sketches or anonymous handcraft atmosphere; no actual product claim | `Artwork kind="bespoke"` on home and bespoke route |
| H04 — designer/craft atmosphere | 4:5 portrait | Anonymous hands/tools or abstract making; never a fake Yvonne portrait/studio | `Artwork kind="craft"` |
| H05 — engagement | 4:5 or 3:2 | Abstract ring geometry, negative space, mineral light; no named inventory | `Artwork kind="wedding"` |
| H06 — material macro | 3:2 | Metal surface, polish and precise marks; no unsupported gem identification | `Artwork kind="material"` |
| H07 — social/OG | 1.91:1, 1200×630 | Typographic YVONNE ROSS plus abstract metal study and unofficial concept mark | Metadata text only at present |
| H08 — optional hero loop | 5–8 seconds, desktop 16:9 or 21:9 | Moving light over an abstract form, no product fiction | `HeroMedia` video prop; only mounts near viewport on desktop without reduced motion; static poster/mobile fallback |

Priority: H01/H02, H03, H04, H05, H06, H07, then H08. Curated named jewellery needs authorised actual product photography separately; the reel currently links to real official listings and uses abstract studies. Before replacing an artwork, verify rights, commercial usage, accurate labelling and crop at 375, 390, 430, 768, 1024, 1280, 1440 and 1728px.
